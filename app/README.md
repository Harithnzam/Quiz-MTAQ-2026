# MTAQ 2026 - Study & Quiz App

A self-contained web app to prepare for the MTAQ 2026 quiz. It has:

- **Interactive quiz** for Round 1-4 (multiple-choice, true/false, and matching),
  with instant scoring and a review of wrong answers.
- **Structured-question review** (open questions with suggested answers) per round.
- **Source-book notes** - key points for each of the four prescribed books.

## How to run

The app loads JSON data, so it must be served over HTTP (not opened as a file).

From the `app/` folder:

```bash
python -m http.server 8765
```

Then open http://localhost:8765 in your browser.

To stop the server, press `Ctrl+C` in that terminal.

### Windows shortcut

Double-click `start.bat` (in this folder) to launch the server and open the app.

## Features

- **Reveal-mode toggle** (per session, remembered):
  - *Instant* — answer + justification shown after each question.
  - *End* — full answer summary + justifications shown at the end.
- **Question categories** — pick any mix per round:
  - Aneka Pilihan (MCQ), Betul/Salah (True/False), Padanan (Matching),
    Konsep (auto-built fact MCQs), Pilih Semua (multi-select).
- **Session length** — 10 / 20 / 30 / all questions, drawn at random.
- **Scoring** — 10 points per correct answer plus streak bonuses (+3 after 3 in a row,
  +5 after 5). Live points/correct/wrong tally, animated result donut, and scoreboard.
- **Rich source-book notes** — 9-13 sections (~50-66 points) per book, multi-page reading.
- **Glassmorphism dark UI**, 2×2 card layout, responsive on desktop and mobile.
- **Keyboard support** — A-D / 1-4 to answer, B/S for true/false, Enter for next.
- **Source-book notes** with verification badges.
- Settings and reveal preference persist via `localStorage`.

## Notes on the data

- Questions come from the supplied Question Banks (3 sets each for Rounds 1-3, 2 for Round 4).
- Round 1-3 notes are verified against the actual source books.
- Round 4 notes are drawn from the Question Bank because the source PDF is a scanned
  Jawi image with no extractable text (see `../SYNC_ANALYSIS.md`).
- In most sets the correct MCQ answer is placed at option **A** by the QB authors. The app
  **shuffles question order** but keeps options in place, so relying on "always A" will not
  help you learn - answer on the meaning.

## Rebuilding the quiz data

If the Question Banks change, re-extract and rebuild:

```bash
cd ..
python extract_all.py       # re-extract QB docx -> extracted/*.txt
python extract_penawar.py   # extract Rumi Penawar Bagi Hati parts (Round 4 source)
python build_notes.py       # rebuild notes.json (rich notes, all 4 rounds)
python build_data.py        # rebuild quiz.json AND auto-generate note-derived MCQs
```

`build_data.py` automatically chains `gen_mcq.py`, which reads `notes.json` and
generates extra fact-based MCQs (definition / fact / cloze) so every round has
100+ MCQ questions. Distractors come from sibling note points to stay plausible.

MCQ counts: Round 1 ~137, Round 2 ~123, Round 3 ~107, Round 4 ~109.
